Реализация события «Воскресный переполох» (Time-gated механика)

1. Утилита времени (server/utils/eventTime.ts):
Напиши функцию getEventPhase(), которая возвращает текущую фазу события по московскому времени (UTC+3).

Используй библиотеку date-fns или dayjs с плагином utc и timezone.

Если сейчас не воскресенье — возвращает null.

Если воскресенье и время с 00:00 до 11:59:59 — возвращает "DISCOUNT_PHASE".

Если воскресенье и время с 12:00 до 23:59:59 — возвращает "WAR_PHASE".

2. Эндпоинт покупки подданных (POST /api/market/buy):

В начале обработчика проверяй: if (getEventPhase() === 'DISCOUNT_PHASE') { price = Math.floor(price * 0.5); }.

В ответе API возвращай текущую цену и флаг isDiscounted: true, чтобы клиент мог показать зачеркнутую старую цену.

Важно: Убедись, что скидка не применяется к эндпоинту выкупа себя (/api/market/buyout-self).

3. Эндпоинт объявления войны (POST /api/clan/war/declare):

В самом начале обработчика проверяй: if (getEventPhase() !== 'WAR_PHASE') { return res.status(403).json({ error: 'Войны доступны только с 12:00 до 00:00 по МСК в воскресенье' }); }.

Далее логика проверки кланов и региона.

4. Эндпоинт статуса события (GET /api/event/status):
Создай эндпоинт, который возвращает клиенту текущее состояние, чтобы фронтенд мог отрисовать баннер:

json
{
  "eventName": "Воскресный переполох",
  "phase": "DISCOUNT_PHASE" | "WAR_PHASE" | "INACTIVE",
  "timeLeft": 43200 // секунды до конца текущей фазы или до начала события
}
